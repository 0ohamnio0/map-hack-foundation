# Map Hack

조울증 발병과 약물 치료 경험을 1인칭/3인칭 미로 탐색으로 표현하는 5~10분짜리 웹 인터랙티브 게임.

## Repo

- GitHub Pages: https://0ohamnio0.github.io/map-hack-foundation/

## Stack

- Vite 6
- React 19 + TypeScript
- React Three Fiber
- Zustand
- @react-three/rapier + ecctrl

## Quick Start

```bash
npm i
npm run dev
```

## Project Notes

- Internal docs are maintained separately and are not included in this public README.

## Deploy (GitHub Pages)

```bash
npm run build
npm run deploy
```

- 배포 브랜치: `gh-pages`
- 배포는 수동으로만 진행 (공유 중인 외부 공개 상태 유지)
